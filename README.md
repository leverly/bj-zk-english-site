# 北京中考领航 · 北京中考英语备考站

把北京中考英语的**课标词汇、语法体系、学阅读、书面表达**做成一个可计数、可练习、可复习的静态网站。

覆盖笔试卷面 **60 分全部五道大题**（听说机考 40 分需专用音频与录音评测，不在本站范围）。

## 直接打开

```bash
open index.html          # 双击也行，无需服务器、无需构建
```

站点把数据内联进了每个页面，所以 `file://` 协议下也能正常工作。

## 考纲依据

北京中考英语总分 **100 分** = 笔试 **60 分** + 听说机考 **40 分**。笔试 90 分钟、共 38 小题、五道大题：

| 题型 | 题量 | 分值 |
|---|---|---|
| 一、单项填空 | 12 小题 | 12 分 |
| 二、完形填空 | 8 小题 | 8 分 |
| 三、阅读理解 | 13 小题 | 26 分 |
| 四、阅读表达 | 4 小题 | 4 分 |
| 五、书面表达 | 1 题 | 10 分 |

听说机考四节：听后选择 12 分 · 听后回答 8 分 · 听后记录并转述 12 分 · 朗读短文 8 分。

## 学习闭环

```
词汇（1755 条）──→ 背单词（quiz.html）──→ 记忆库 ──→ 按遗忘曲线排下次

语法（57 考点）──→ 练语法（review.html）─→ 考点正确率 + 错题本
                        ↑
                 304 道题按考点分组供应

篇章（20 篇 138 题）──→ 学阅读（reading.html → 类型 → 单篇）──→ 原文定位解析 + 能力诊断 + 错题本
                            ↑
                  完形 4 篇 / 阅读 16 篇 / 阅读表达 40 题

写作（方法 + 范文）──→ 书面表达（总览 → 4 个方法页 / 8 篇范文页）──→ 五步法 + 模板 + 句型库 + 失分点 + 范文对照
```

三个独立的记忆回路：

- **背单词**：每个词答完写入记忆库。忘了 → 10 分钟后再来；会了 → 按 ease 因子拉长间隔（1 天 → 3 天 → 7 天 → 21 天以上）。四选一干扰项取自同主题、同词性，并排除释义高度重叠的词。
- **练语法**：记录每个考点的累计正确率与具体错题。答对的题按 0.5/1/3/7/21/60 天排期，未到期不再重复出题；正确率低的考点可「专攻最弱考点」。
- **学阅读**：完形、阅读、阅读表达的错题统一进错题本，答对一次即出册。每题解析给「原文定位句 + 为什么对 + 错项为什么错」，可回原文逐字核对。
- **阅读能力诊断**：六项能力（细节定位 / 主旨与观点 / 推理判断 / 上下文逻辑 / 固定搭配 / 语法与词形）——阅读选择题按题干规则自动归类，完形填空 32 空为人工逐空标注；统计各维度正确率并按最弱在前排序，未作答项显示 0 / 0 与「—」。

### 释义与词性处理

直接从词典取会有三个问题，脚本里都做了处理：

1. **义项顺序和词性错乱** —— `go` 会给出「打赌/保释金」。按词性优先取义，并过滤 `[计]`/`[化]` 这类领域标注。
2. **词性识别错误** —— ECDICT 的 `definition` 字段用**字面 `\n`** 分隔义项，不先还原成真换行就匹配不到行首词性标记，会导致几乎所有词都被兜底成名词。脚本先还原换行再投票。
3. **高频功能词词性不可靠** —— `the` 会被 WordNet 投成动词、`three` 被投成名词。这类词走人工覆盖表（`POS_OVERRIDE`）。

### 分档口径

按语料词频（COCA/BNC 取更常用者）分三档：

- **核心高频**（955，含 155 条短语）：词频前 1000，卷面最常遇到
- **中频主力**（686）：1000–5000，阅读与写作主力
- **拓展词**（114）：其余

这是启发式分档，不是官方等级标注。

### 主题归类

按关键词规则同时匹配英文词形与中文释义，一个词可归入多个主题，未命中归「通用高频」。这是按词义的参考归类，不是官方话题划分。

## 改内容

```bash
# 改词表（释义 / 短语 / 词性 / 主题）
$EDITOR reference/build_words.py     # OVERRIDE / POS_OVERRIDE / THEME_RULES
$EDITOR reference/phrases.py         # 短语表
python3 reference/build_words.py     # 重新生成 src/data-words.js

# 改语法、题目、阅读、写作（手写数据源）
$EDITOR src/data-grammar.js          # 语法族 / 考点 / 易错对比
$EDITOR src/data-quiz.js             # 第一批 160 题
$EDITOR src/data-quiz2.js            # 第二批 144 题

# 重新生成站点
node build-site.mjs
```

构建结束会打印数据规模，并在有考点没有对应题目时退出码 1。

## 已知限制

- 词表为公开词典标签 + 人工校正，**不等于官方发布的考试词汇表**，个别词可能超出或低于本地中考范围。
- 语法考点、练习题、完形、阅读与写作练习均为按北京卷题型编写的**原创内容**，不是官方真题。
- 题库分两批：第一批 160 题打底，第二批 144 题定向补齐低频考点、语境化变式、填空改错与易混对比，现已做到每个考点 ≥4 题。
- 学阅读为 16 篇阅读 + 4 篇完形，阅读表达 40 题；篇目数少于真实卷面套数，用于按类型反复练读法，不是完整套卷。
- 阅读表达按**关键词组匹配**判分，只检查信息点是否答到，不评判语法与拼写细节；真实阅卷会看语言质量。
- 写作部分提供方法体系与 **8 篇原创高分范文**，**不做自动批改**；范文是原创仿写，不是官方满分作文，写完请对照评分要点与失分点自查。
- 听说机考 40 分需专用音频与录音评测，**不在本站范围**。
- 词频分档是启发式推断，不要当作官方难度等级。
- 学习记录存在浏览器 localStorage，换浏览器或清缓存会丢失，请用「学习数据」页导出备份。
- 全站朗读音频由 **Edge TTS（en-GB-SoniaNeural）预生成**，共 1913 条 25MB，音色统一；个别新增文本若尚未生成音频，才退回浏览器语音合成。

### 朗读音频生成

站点所有朗读（单词、范文、句型、阅读原文）都用 **Edge TTS** 预生成，音色统一为
`en-GB-SoniaNeural`（英式女声），rate `-10%`，转成 mono 32kbps 的 mp3。

```bash
python3 -m venv /tmp/ttsenv && /tmp/ttsenv/bin/pip install edge-tts
node tools/dump_audio_texts.mjs > /tmp/audio-texts.json   # 导出待朗读文本
/tmp/ttsenv/bin/python tools/gen_audio.py                 # 增量生成（已有文件跳过）
/tmp/ttsenv/bin/python tools/gen_audio.py --force         # 全部重生成
node build-site.mjs                                       # 重新构建，音频映射会内联进页面
```

`gen_audio.py` 会写出 `src/data-audio.js`（「朗读原文 → mp3 路径」映射）。
构建时按页面类型只内联该页需要的条目：词库页约 59KB，范文页约 1KB。

### 题库校验

```bash
node tools/validate.mjs
```

校验项：locate 是否能在原文逐字定位、解析是否完整、写作练习要点是否齐全、
选项是否重复、答案是否越界、考点是否全部有题。新增题目后务必跑一遍。
