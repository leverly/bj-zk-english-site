📐 句型

句型决定句子的骨架。中考重点：there be、疑问句、祈使句、感叹句。

there be 句型 基础 4 题
规则

there be 表示「某地有某物」，be 的形式由后面第一个名词决定（就近原则）。不能与 have 混用。

构成 / 形式
There is/are + 名词 + 地点 ｜ 否定：There isn't/aren't ｜ 疑问：Is/Are there…?
例句
There is a book on the desk.
桌上有一本书。
There are some students in the classroom.
教室里有一些学生。
Is there any milk in the fridge?
冰箱里有牛奶吗？
中式易错避坑
there be 与 have 混用
✕There have a book on the desk.
✓There is a book on the desk.
there be 表「存在」，have 表「拥有」，不能混用。
就近原则用错
✕There are a pen and two books.
✓There is a pen and two books.
there be 的 be 与最靠近的名词一致（a pen 单数）。
将来时漏 be
✕There will a meeting tomorrow.
✓There will be a meeting tomorrow.
there be 的将来时是 there will be，不能省略 be。

疑问句 基础 5 题
规则

一般疑问句用 yes/no 回答；特殊疑问句以疑问词开头；反意疑问句「前肯后否、前否后肯」。

构成 / 形式
一般：助动词 + 主语 + 动词 ｜ 特殊：疑问词 + 助动词 + 主语 + 动词
例句
Do you like music?
你喜欢音乐吗？
Where did you go last Sunday?
上周日你去哪儿了？
He is a student, isn't he?
他是学生，不是吗？
中式易错避坑
特殊疑问句用倒装错误
✕Where you did go?
✓Where did you go?
特殊疑问句要把助动词提到主语前：疑问词 + 助动词 + 主语 + 动词。
反意疑问句前后同向
✕He is a student, is he?
✓He is a student, isn't he?
反意疑问句「前肯后否、前否后肯」。

祈使句 基础 4 题
规则

祈使句以动词原形开头，表示命令、请求、建议；否定用 Don't + 动词原形。

构成 / 形式
V + … ｜ Don't + V + … ｜ Let's + V ｜ Please + V
例句
Open the door, please.
请开门。
Don't be late for class.
上课别迟到。
Let's go to the park.
我们去公园吧。
中式易错避坑
祈使句加主语 you
✕You open the door.
✓Open the door.
祈使句通常省略主语 you，直接以动词原形开头。
否定祈使句用 not to
✕Not to be late.
✓Don't be late.
否定祈使句用 Don't + 动词原形。

感叹句 重点 4 题
规则

what 修饰名词（what a/an + adj + 单数可数名词），how 修饰形容词或副词。

构成 / 形式
What + (a/an) + adj + n + 主谓! ｜ How + adj/adv + 主谓!
结构例句
What a/an + adj + 单数可数名词What a beautiful girl she is!
What + adj + 复数/不可数名词What fine weather it is!
How + adj + 主谓How beautiful the girl is!
How + adv + 主谓How fast he runs!
How + 主谓（省略形容词）How time flies!
例句
What a clever boy he is!
他真是个聪明的男孩！
What fine weather it is!
天气真好！（weather 不可数，不加 a）
How hard he works!
他工作多努力啊！
中式易错避坑
不可数名词前加 a
✕What a fine weather!
✓What fine weather!
weather / news / advice 等不可数名词前不加 a/an。
what 与 how 混用
✕How a beautiful girl!
✓What a beautiful girl!
中心词是名词用 what；中心词是形容词/副词用 how。

倒装与强调 难点 4 题
规则

so / neither 引导的倒装表示「也是/也不」；强调句 It is/was … that … 用来突出某成分。

构成 / 形式
So + 助动词 + 主语 ｜ Neither + 助动词 + 主语 ｜ It is/was + 被强调部分 + that/who
例句
—I like music. —So do I.
——我喜欢音乐。——我也是。
—I can't swim. —Neither can he.
——我不会游泳。——他也不会。
It was in the park that I met him.
我就是在公园遇到他的。（强调地点）
中式易错避坑
so 倒装时助动词与主语不一致
✕—I like music. —So I do.
✓—I like music. —So do I.
表示「我也是」时用倒装 So + 助动词 + 主语；So I do 是「确实如此」的意思。
