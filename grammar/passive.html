🔄 被动语态

主语是动作的承受者时用被动语态。中考重点是各时态的被动构成和不及物动词无被动。

被动语态的构成 重点 10 题
规则

被动语态 = be + 过去分词。时态变化体现在 be 上，过去分词不变。

构成 / 形式
am/is/are done ｜ was/were done ｜ will be done ｜ have/has been done ｜ can be done
时态被动结构例句
一般现在时am/is/are + doneEnglish is spoken in many countries.
一般过去时was/were + doneThe bridge was built in 1990.
一般将来时will be + doneThe work will be finished tomorrow.
现在完成时have/has been + doneThe homework has been checked.
含情态动词情态动词 + be + doneThe book can be found in the library.
现在进行时am/is/are being + doneThe road is being repaired.
例句
English is spoken in many countries.
许多国家说英语。
The bridge was built in 1990.
这座桥建于 1990 年。
The work must be finished today.
这项工作必须今天完成。
中式易错避坑
漏掉 be 动词
✕The house built in 1990.
✓The house was built in 1990.
被动语态必须是 be + 过去分词，不能只有过去分词。
过去分词写成过去式
✕The window was broke by the boy.
✓The window was broken by the boy.
被动语态用过去分词 broken，不是过去式 broke。
不及物动词用被动
✕An accident was happened yesterday.
✓An accident happened yesterday.
happen / appear / arrive / rise / die 等不及物动词没有被动语态。

主动与被动的转换 重点 4 题
规则

主动变被动：宾语变主语，动词变 be + 过去分词，原主语变 by 短语（可省略）。

构成 / 形式
主动：A does B → 被动：B is done by A
例句
Tom cleans the room every day.
汤姆每天打扫房间。
The room is cleaned by Tom every day.
房间每天由汤姆打扫。
They will hold a meeting tomorrow.
他们明天要开会。
A meeting will be held tomorrow.
明天将举行一次会议。
中式易错避坑
双宾语动词转换错误
✕I was given a book to him.
✓He was given a book. / A book was given to him.
give sb sth 变被动有两种：以人为主语（He was given…）或以物为主语（A book was given to him）。
by 短语位置错误
✕The room by Tom is cleaned.
✓The room is cleaned by Tom.
by 短语放在句末，紧跟动词之后。

主动形式表被动 难点 4 题
规则

某些动词（sell, open, close, write, read, wash, cut, lock, drive）用主动形式表被动意义，主语通常是物。

构成 / 形式
主语（物）+ 动词主动形式 + 副词
例句
This kind of book sells well.
这种书很好卖。
The shop opens at eight.
这家店八点开门。
This pen writes smoothly.
这支笔写起来很顺。
中式易错避坑
该用主动表被动却写被动
✕This book is sold well.
✓This book sells well.
sell / open / write 等表「本身特性」时用主动形式，配合 well / smoothly 等副词。
