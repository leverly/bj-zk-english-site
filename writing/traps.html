⚠️ 六个最高频的失分点

时态混用、第三人称单数漏 -s、可数名词忘复数、字数不足、要点漏写、全文无连接词。写完对照这张表自查，能救回 1–2 分。

✕ 时态混用
记叙用过去时，通知/介绍用现在或将来时。一篇里不能一会儿过去一会儿现在。
✓ 下笔前先定一个主时态，全文跟着它走。
✕ 第三人称单数漏 -s
He go / She like / My father work 是最高频的拼写类失分。
✓ 写完专门扫一遍所有动词，主语是 he/she/it/单数名词的加 -s。
✕ 可数名词忘复数
many student / two book / some friend
✓ 看到 many / some / two 后面的名词，先确认加没加 -s。
✕ 字数不足
低于 60 词会明显扣分，常见于「要点写得太简单」。
✓ 每个要点至少写两句：一句陈述 + 一句展开（原因/例子）。
✕ 要点漏写
题目给 3 条要点只写了 2 条，内容分直接掉一档。
✓ 写完逐条对照题目打勾，缺的补一句。
✕ 全文无连接词
句子之间没有 First / Second / Besides，读起来像散句堆叠。
✓ 每个理由前加一个连接词，成本最低、得分最明显。

📝 交卷前的最后检查

  1. 题目给的 3 条要点，是否每条都有对应句子？
  2. 全文时态是否统一？
  3. 第三人称单数的动词都加 -s 了吗？
  4. many / some / two 后面的名词加 -s 了吗？
  5. 每个理由前有 First / Second / Besides 这类连接词吗？
  6. 字数够 80 词 了吗？
